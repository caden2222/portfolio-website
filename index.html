01 / Models / Natural language processing

Customer Review Sentiment Analysis

From pizza reviews to sentiment patterns. Exploring recurrent models through text preprocessing, tuning and baseline comparison.

  • Python
  • TensorFlow
  • Keras
  • NLP

Problem & objective

Explore how recurrent neural networks can classify sentiment in pizza reviews, and how a BiGRU model compares with an RNN baseline.

My contribution

I built RNN and BiGRU models, preprocessed the review text, tuned the models and evaluated performance against the RNN baseline.

Approach & tools

  1. Preprocess the review text for model input.
  2. Build and tune recurrent models using Python, TensorFlow and Keras.
  3. Evaluate the BiGRU model against the RNN baseline.

Project record

The project work includes text preprocessing, model tuning and baseline evaluation. The diagram below illustrates that workflow; it is not a model output.

Review textPreprocessRNN / BiGRUEvaluate

Limitations

Accuracy and F1 results are not published here. A baseline comparison is the focus of this study; the available evidence does not establish performance on new domains or deployment readiness.

Learning

The learning objective was to connect text preparation, recurrent architecture choices and evaluation in one sentiment-analysis workflow.

Graduate Employment & Salary Trends

Exploring graduate outcomes across institutions from 2018–2023, with salary comparisons and a closer look at employment cohorts.

  • Power BI
  • Data Analysis
  • Data Visualisation

Problem & objective

Explore how graduate salary and employment patterns vary across institutions and years, including fresh and post–National Service graduates.

My contribution

My contribution focused on salary trends and exceptions across institutions, employment patterns by institution, and comparisons between fresh and post–National Service graduates. The shared dashboard labels these panels with my name; other panels were created by a teammate.

Approach & tools

  1. Use Power BI to compare salary trends across institutions from 2018–2023.
  2. Examine employment patterns across institutions and employment types.
  3. Compare outcomes for fresh and post–National Service graduates.

Project record

Original group dashboard. Caden-labelled panels show my contribution; the whole dashboard is shared group work. Open the full image to inspect the labels.

Limitations

These are descriptive comparisons, not evidence that institution or National Service status causes an outcome. Aggregated figures depend on the selected year and cohort; no business-impact claim is made.

Learning

The learning objective was to make differences between institutions and cohorts easier to examine through visual comparison.

04 / Software / Learning interface

Analogy Tutor

A learning-interface prototype for query, key and value concepts, with separate scripted and generated reply modes.

  • JavaScript
  • Node.js
  • Express
  • Groq API

Problem & objective

Explore how analogies can introduce query, key and value concepts, with a clear distinction between a fixed teaching example and a generated explanation.

My contribution

This repository brings together a browser learning interface and an Express backend. The implementation separates scripted replies from generated replies, manages conversation sessions, and handles provider errors. These are source-verified implementation details; live model behaviour has not been validated for this portfolio.

Approach & tools

  1. Offer explicitly selected scripted and generated reply modes.
  2. Route requests through Express with separate in-memory conversation sessions.
  3. Use a server-side Groq API provider for generated replies, with structured response validation and timeout handling.

Project record

The linked source contains the session and chat routes in server.js and a real model API request in server/groq-provider.js. Scripted mode uses a separate provider. The workflow below is illustrative.

Learner requestSelected reply modeProviderResponse

Limitations

This is a prototype. Generated mode requires a configured backend API key; it is not hosted inside this static portfolio. No live model request was tested during this redesign, and generated explanations may be inaccurate. Interactive graphics are separate from reply generation.

Learning

The learning focus is the boundary between interface behaviour, deterministic teaching content and model-generated responses.
