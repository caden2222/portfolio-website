FinTech Hackathon

Gamified Insurance Platform

Developed a web-based prototype during the Prudential FinTech Hackathon to encourage younger users to learn about insurance through a simple and engaging gamified experience.

React HTML CSS JavaScript

Overview

Project Objective

Insurance products are often viewed as complicated and difficult for younger individuals to understand.

Our team designed a simple gamified platform to make learning about insurance concepts more engaging and interactive.

My Role

Frontend Development

Contributed to the development of the web interface using React, HTML and CSS.

Worked closely with teammates to implement the user interface and transform ideas into a working prototype.
