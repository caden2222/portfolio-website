Academic project · Sentiment analysis

Customer Review Sentiment Analysis

From pizza reviews to sentiment patterns. Exploring recurrent models through text preprocessing, tuning and baseline comparison.

  • Python
  • TensorFlow
  • Keras
  • NLP

01 / THE QUESTION

Problem & objective

Explore how recurrent neural networks can classify sentiment in pizza reviews, and how a BiGRU model compares with an RNN baseline.

02 / MY PART

My contribution

I built RNN and BiGRU models, preprocessed the review text, tuned the models and evaluated performance against the RNN baseline.

03 / THE PROCESS

Approach & tools

  1. Preprocess the review text for model input.
  2. Build and tune recurrent models using Python, TensorFlow and Keras.
  3. Evaluate the BiGRU model against the RNN baseline.

04 / PROJECT RECORD

Workflow overview

05 / CONTEXT

Limits of this work

Accuracy and F1 results are not published here. A baseline comparison is the focus of this study; the available evidence does not establish performance on new domains or deployment readiness.

06 / LEARNING

Connecting the pieces

The learning objective was to connect text preparation, recurrent architecture choices and evaluation in one sentiment-analysis workflow.
