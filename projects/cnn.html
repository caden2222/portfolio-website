Machine Learning

CNN Image Classification

Developed a Convolutional Neural Network (CNN) to classify handwritten letters using the EMNIST Letters dataset. The project explored deep learning techniques including preprocessing, model optimisation and evaluation to improve classification performance.

Python TensorFlow Keras NumPy Matplotlib

Overview

Project Objective

The objective of this project was to develop a machine learning model capable of recognising handwritten English letters from the EMNIST dataset.

A Convolutional Neural Network was implemented using TensorFlow and Keras to learn image features and accurately classify 26 alphabet classes.

Dataset

EMNIST Letters

The EMNIST Letters dataset contains thousands of grayscale handwritten character images.

Images were normalised and preprocessed before being used to train and evaluate the CNN model.

Model Pipeline

Development Process

Data Preprocessing

Normalised image pixel values and prepared the EMNIST dataset for model training.

CNN Architecture

Designed and trained a convolutional neural network using TensorFlow and Keras.

Model Evaluation

Evaluated the model using validation accuracy and loss to monitor performance.

Performance Optimisation

Improved model performance through hyperparameter tuning and preprocessing techniques.

Challenges

Key Challenge

One of the biggest challenges was improving model accuracy without significantly increasing overfitting. Multiple preprocessing techniques and parameter adjustments were evaluated before selecting the final model.
