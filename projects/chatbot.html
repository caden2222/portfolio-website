Generative AI Project

AI Burnout Support Chatbot

An AI-powered chatbot designed to provide users with supportive and contextual responses when discussing stress, burnout and personal well-being.

OpenAI API Natural Language Processing Prompt Engineering Conversational AI

Overview

Project Background

Burnout and prolonged stress can affect a person's productivity, motivation and overall well-being. However, some users may find it difficult to express their concerns or identify suitable next steps.

This project explored how conversational AI could provide an accessible space for users to reflect on their feelings and receive relevant, supportive responses.

Objective

What I Built

I developed a chatbot that accepts natural-language messages and generates contextual responses using the OpenAI API.

The system was designed to maintain a supportive conversational tone while encouraging users to reflect on their stress and consider practical well-being strategies.

Functionality

Key Features

Contextual Conversations

Generates responses based on the user's message rather than relying only on fixed, predefined answers.

Supportive Response Style

Uses prompt instructions to maintain an understanding, respectful and non-judgmental tone.

OpenAI API Integration

Connects the chatbot interface to a generative AI model through API requests.

User-Focused Interaction

Presents responses through a straightforward chat interface that is easy for users to understand.

Contribution

What I Worked On

01

Chatbot Concept and User Flow

Planned how users would interact with the chatbot and how the system would process and display conversational responses.

02

Prompt Engineering

Designed and refined prompts to guide the AI toward responses that were relevant, supportive and appropriate to the chatbot's purpose.

03

API Integration

Connected the application to the OpenAI API and handled the exchange of user messages and AI responses.

04

Testing and Refinement

Tested different conversation scenarios and adjusted the prompts to improve response consistency and usefulness.

Challenge

Maintaining Relevant Responses

A major challenge was ensuring that the chatbot remained focused on burnout support without producing responses that were overly generic or unrelated to the user's situation.

I addressed this by refining the prompt instructions and testing the chatbot with different types of user input.

Learning

Key Takeaways

  • How prompt wording affects generative AI responses.
  • How to integrate an AI model through an API.
  • How to design conversations around user needs.
  • The importance of testing AI outputs across different scenarios.

Responsible Use

This chatbot was created as a student project and is intended to provide general supportive conversation. It is not a replacement for professional medical or mental-health advice.
